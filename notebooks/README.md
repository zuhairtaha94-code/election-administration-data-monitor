# Notebooks

Notebooks will be numbered in execution order:

- `01_data_audit.ipynb` — schema, missing values, identifiers, and candidate variables
- `02_metric_validation.ipynb` — denominator checks and analytical metric construction
- `03_outlier_analysis.ipynb` — peer-group comparisons and robust outlier triage
- `04_reporting.ipynb` — final figures, tables, and stakeholder-facing findings

Reusable logic will be moved into `src/` rather than duplicated across notebooks.
