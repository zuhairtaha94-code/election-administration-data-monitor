# Data

## Planned source files

The analysis will use Version 2.0 of the **2024 Election Administration and Voting Survey (EAVS)** and its official codebook, published by the U.S. Election Assistance Commission.

- Dataset landing page: https://www.eac.gov/research-and-data/studies-and-reports
- 2024 EAVS Version 2.0 CSV archive: https://www.eac.gov/sites/default/files/2026-02/2024_EAVS_for_Public_Release_nolabel_V2_csv.zip
- 2024 EAVS codebook: https://www.eac.gov/sites/default/files/2025-06/2024_EAVS_Codebook.xlsx

## Directory policy

- `raw/` contains unchanged files obtained from the official publisher.
- `processed/` contains files generated by reproducible project code.
- Raw and processed data are excluded from Git because they may be large and can be recreated from the documented sources.
- Small metadata files, integrity checks, and data dictionaries may be committed when useful for reproducibility.

## Data acquisition status

The source release and expected SHA-256 checksums are recorded in `source_manifest.json`.

From the repository root, acquire and verify the files with:

```bash
python scripts/download_eavs.py
```

The download script fails if a file does not match the documented release. Run the initial source audit with:

```bash
python scripts/audit_source_data.py
```

Build the ignored, analysis-ready jurisdiction file and the committed validation summary with:

```bash
python scripts/build_analysis_dataset.py
```

The build produces `data/processed/analysis_jurisdictions.csv`. The processed CSV is excluded from Git because it is reproducible from the official source files and project code.

Run the state-aware screen with:

```bash
python scripts/run_outlier_triage.py
python scripts/create_figures.py
```

This produces the ignored `data/processed/outlier_triage.csv`, a committed summary of the screening results, and publication-ready figures.
